# Windows 初版验收

环境：Windows 11 x64，两台设备处于同一局域网。另一端可以是 macOS 14.2+ 或 Windows 11。CI 使用合成音频验证传输，以下步骤验证实际系统采集与桌面行为。

1. 从成功的 Actions 运行下载 `EnjoySync-windows-x64`，解开下载文件及其中的 ZIP，运行 `EnjoySync/EnjoySync.exe`。
2. 如果 Windows 防火墙弹窗出现，允许应用在当前用于测试的网络上通信。从托盘菜单“设置…”或右上角齿轮打开本机设置，复制发送端连接密钥。两端的监听端口默认均为 UDP 51000，可在设置窗口分别修改。
3. 接收端填写发送端 IP、端口和发送端的连接密钥，点击“添加并连接”。也可以在地址栏直接粘贴 `IP:端口`，添加成功后应自动拆分到地址和端口栏；已有的这类旧记录应在启动时自动修复。两端应各出现一条“已连接”设备记录。
4. 发送端开启对应设备行的“共享”，并保持全局“允许共享系统声音”开启。接收端开启“接收”和“播放”。在发送端用浏览器或播放器播放普通音频；接收端应能听到，发送端本地播放继续正常。
5. 设备操作均为图标，悬停应显示“接收”“播放”“共享”“自动连接”“断开 / 重连”“移除”等提示，高亮应与开关状态一致。接收端关闭“播放”，应立即静音；重新开启后恢复。关闭“接收”应停止订阅；音量滑块应只影响该设备在本机的播放，旁边百分比应实时更新。
6. 重复添加同一地址，应保持一条设备记录。主动点击“断开”，两端应显示离线且停止自动重试；点击“重连”应恢复。
7. 用任务管理器结束一端进程，另一端应在约 5 秒后显示离线并进入重连。重新运行被结束的一端，应恢复连接和音频。
8. 勾选“自动连接”，从托盘菜单正常退出后重新运行，验证启动恢复。最小化或关闭窗口后应进入托盘且继续传输，点击托盘图标应恢复窗口。
9. 将播放设备格式改为 44.1 kHz，再测试音频。也可切换 PCM，检查恢复后能持续播放。记录是否有杂音、持续静音或异常占用。
10. 默认外观应随 Windows 应用颜色模式变化；设置中手动选择“浅色”“深色”应即时同步主窗口、设置窗口、菜单及标题栏，重启后保留选择。切回“跟随系统”后应恢复自动变化。

反馈时提供 Windows 版本、两端系统、发送方向、输出设备、Opus/PCM、缓冲值、复现步骤，以及界面的状态或错误文字。截图请遮住连接密钥；不要公开包含密钥的 `settings.json`。
