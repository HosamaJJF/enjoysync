# Windows 初版验收

环境：Windows 11 x64，两台设备处于同一局域网。另一端可以是 macOS 14.2+ 或 Windows 11。CI 使用合成音频验证传输，以下步骤验证实际系统采集与桌面行为。

1. 从成功的 Actions 运行下载 `EnjoySync-windows-x64`，解开下载文件及其中的 ZIP，运行 `EnjoySync/EnjoySync.exe`。
2. 如果 Windows 防火墙弹窗出现，允许应用在当前用于测试的网络上通信。从托盘菜单“设置…”或右上角齿轮打开本机设置，复制发送端连接密钥。两端的监听端口默认均为 UDP 51000，可在设置窗口分别修改。
3. 接收端填写发送端 IP、端口和发送端的连接密钥，点击“添加并连接”。也可以在地址栏直接粘贴 `IP:端口`，添加成功后应自动拆分到地址和端口栏；已有的这类旧记录应在启动时自动修复。两端应各出现一条“已连接”设备记录。
4. 发送端开启对应设备行的“共享”，并保持全局“允许共享系统声音”开启。接收端开启“接收”和“播放”。在发送端用浏览器或播放器播放普通音频；接收端应能听到，发送端本地播放继续正常。
5. 设备操作均为图标，悬停应显示“接收”“播放”“共享”“自动连接”“断开 / 重连”“移除”等提示，高亮应与开关状态一致。接收端关闭“播放”，应立即静音；重新开启后恢复。关闭“接收”应停止订阅；音量滑块应只影响该设备在本机的播放，旁边百分比应实时更新。
6. 重复添加同一地址，应保持一条设备记录。主动点击“断开”，两端应显示离线且停止自动重试；点击“重连”应恢复。
7. 用任务管理器结束一端进程，另一端应在约 5 秒后显示离线并进入重连。重新运行被结束的一端，应恢复连接和音频。
8. 勾选“自动连接”，从托盘菜单正常退出后重新运行，验证启动恢复。最小化或关闭窗口后应进入托盘且继续传输，点击托盘图标应恢复窗口。
   在“设置 → 通用”中开启“开机自启动”，无需点击保存；关闭再打开设置窗口，选项应保持勾选。注销并重新登录 Windows 后应自动启动，已勾选自动连接的设备应恢复连接。关闭此选项后再次登录，应不再自动启动。另在含空格、中文的程序路径下重复启用，检查当前用户 `Software\Microsoft\Windows\CurrentVersion\Run` 中 EnjoySync 项的程序路径带双引号；关闭后该项应删除，重复关闭也应成功。
   “开机自启动”关闭时，“开机自启动后隐藏到后台”应置灰。开启自启动并勾选隐藏后，注销重新登录应只出现托盘图标，自动连接和音频继续运行；点击图标应恢复界面。退出后手动打开应显示主窗口。取消隐藏后，下次登录应显示窗口。关闭自启动后即使保留隐藏偏好，手动打开或传入 `--autostart` 也应显示界面。旧版本已启用自启动时，勾选隐藏应将 Run 项更新为带引号的程序路径加 ` --autostart`，包含参数的完整命令也须符合 260 字符限制。
9. 将播放设备格式改为 44.1 kHz，再测试音频。也可切换 PCM，检查恢复后能持续播放。记录是否有杂音、持续静音或异常占用。
10. 默认外观应随 Windows 应用颜色模式变化；设置中手动选择“浅色”“深色”应即时同步主窗口、设置窗口、菜单及标题栏，重启后保留选择。切回“跟随系统”后应恢复自动变化。
11. 两端升级到含传输修复的构建，在相同有线局域网下连续共享音频至少 30 分钟，同时检查窗口隐藏后是否稳定。若出现“等待重连 / 安全连接中”，记录发生时间，并保留两端配置目录下的 `logs/transport.log`；比较 `HEARTBEAT_TIMEOUT`、`READ_FAILED`、`WRITE_FAILED`、`NETWORK_LOOP` 和最近的 `HEALTH`，区分无入站数据、原生 UDP 错误、发送拥塞、队列溢出和本机线程停顿。
12. 分别在主窗口显示、设置窗口显示、仅托盘驻留，以及音频传输中执行关机、重启和注销。EnjoySync 应立即允许结束会话，不应出现在阻止关机的应用列表中；重新登录后配置应保留。若系统关机被其他应用取消，EnjoySync 应继续运行。`enjoysync_desktop_tests` 会向本进程的主窗口、设置窗口和托盘发送模拟会话消息，验证立即允许询问、取消后继续运行和确认后请求退出，不会实际关闭系统。
12. 在不影响其他任务时快速重启一端应用，验证旧连接尚未达到 5 秒心跳期限时也能恢复。已确定失联且链路可用时，首轮重连应使用最近成功的地址；不要将 250–500 ms 的重试等待等同于包括故障检测、握手、采集重建和播放缓冲的总断音时间。
13. 在 Windows 显示缩放 100%、150%、200% 下分别右键托盘图标（含托盘折叠区内的图标），菜单应在鼠标旁显示、保持在屏幕可用范围内，中文清晰可读。主窗口显示、最小化和关闭到托盘后均重复检查，并测试“快捷连接”子菜单、菜单操作、点击外部关闭和 Esc 关闭。多显示器使用不同缩放比例时，将主窗口和任务栏放到不同屏幕（含位于主屏左侧的副屏），菜单及子菜单应按任务栏所在屏幕缩放，不能沿用主窗口或隐藏托盘窗口的 DPI。

反馈时提供 Windows 版本、两端系统、发送方向、输出设备、Opus/PCM、缓冲值、复现步骤，以及界面的状态或错误文字。截图请遮住连接密钥；不要公开包含密钥的 `settings.json`。
