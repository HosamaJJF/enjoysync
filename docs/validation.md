# 0.1.0 验证记录

日期：2026-10-13。环境：macOS 27.0.1 / Apple Silicon，Xcode 27.0，CMake 4.4.4。

## 已完成

- Release 原生桌面应用编译通过，产物为 arm64，应用包约 11 MB。
- `ctest --test-dir build-release --output-on-failure`：1/1 集成测试套件通过，最终执行耗时约 22 秒。
- 套件通过真实回环 UDP / DTLS / AOO 数据流验证：IPv4 / IPv6、Opus / PCM、双向音频、44.1 kHz 采集和输出重采样、逐设备静音、错误密钥拒绝、域名别名去重与地址更新、失联识别、同端口重启后的音频恢复、主动断开、双方同时拨号、已保存设备的启动自动连接。
- 对同时拨号的竞争修复进行过 8 轮重复验证，每轮连接和启动恢复均通过。
- 实际启动 GUI，检查中文布局、空地址校验、密钥遮罩；窗口关闭后后台进程保留。
- 应用完成本地 ad-hoc 签名，`codesign --verify --deep --strict` 通过。没有 Developer ID 公证。
- 第三方许可随应用打包。可执行文件仅依赖系统库，已移除未使用的 WebKit 链接。

## 尚未完成

- Core Audio Tap 已编译接入，但没有授予真实系统音频采集权限或进行双机系统声音实测。
- Windows 源码和构建 / 测试 CI 已提供，尚未在 Windows 编译或真机验证。
- Intel Mac / Universal 产物、实际端到端延迟、蓝牙、声卡热插拔、睡眠唤醒、公网环境和长时间资源占用尚待验证。
- 菜单栏恢复入口已实现；自动化读取系统菜单栏遇到超时，该项需人工验收。

合成音频测试不采集或传输用户的真实系统声音，不能替代系统录音授权和实际设备验证。

## 2026-10-14 连接与菜单栏修复

- 修复地址栏粘贴 `IP:端口` 后被整体作为域名解析的问题，支持域名带端口和 `[IPv6]:端口`；内嵌端口优先，并将输入拆分显示。加载时自动修复旧记录并去重。
- macOS 注册 JUCE 原生菜单所需的 `MenuBarModel`，退出时解除注册；普通点击图标恢复窗口，右键打开菜单。应用菜单栏增加“设备”菜单作为另一个入口。
- Release 编译和本地 ad-hoc 签名验证通过；真实回环 UDP / DTLS / 音频与生命周期回归套件通过，覆盖本次新增的输入格式、非法端口、配置迁移和去重。
- 使用修复后的 Mac 应用及原有 Windows 应用，在用户实际局域网中完成 DTLS 配对，界面显示对方设备名称、“已连接”和约 5.5 ms RTT。未开启真实系统音频共享。
- 实际验证应用“设备”菜单可以显示选项并执行“打开 EnjoySync”。关闭主窗口后，系统菜单栏的自动化访问超时，因此图标点击恢复、右键菜单和菜单退出仍需人工验收。
- 本次 Windows 新源码尚未重新编译；共享地址解析代码已纳入跨平台测试套件。

## 2026-10-14 界面调整

- 新增浅色 / 深色主题，默认跟随系统并监听外观变化；独立设置窗口可手动切换，立即应用到主窗口、设置窗口、菜单和原生标题栏，并保存选择。
- 本机名称、端口、缓冲、编码、输出、密钥和 Dock 行为移至独立设置窗口；菜单栏、托盘菜单、主窗口齿轮和 `⌘,` / `Ctrl+,` 提供入口。
- 设备接收、播放、共享、自动连接、断开 / 重连、移除改为图标及悬停提示；高亮表示开启状态，音量旁实时显示百分比。移除内部软件大标题、宣传语、协议说明和冗余状态文案。
- 使用独立配置及三台离线测试设备实际检查了主窗口和设置窗口的深浅布局、手动主题同步、原生标题栏、菜单栏设置入口、macOS 设置快捷键、参数校验 / 保存、播放图标状态以及音量从 80% 到 55% 的即时更新；未改动正在运行实例的配置和音频控制。
- macOS Release 编译通过；包含主题配置保存与旧配置兼容性检查的 UDP / DTLS / AOO 音频回归套件 1/1 通过，耗时约 22 秒。Windows 界面与原生标题栏切换源码已更新，尚未在 Windows 编译或真机验收；实际切换系统外观的自动跟随行为仍待两平台人工检查。
